# 今日头条自动发布说明

## 能力范围

点签内置“今日头条”分发渠道。运营人员可以在文章生产任务中选择该渠道，文章通过风险检查和人工审核后，点击发布即可自动进入分发队列。

系统负责：

- 加密保存接入 Token
- 发送标题、Markdown、HTML、摘要、关键词、分类、作者和图片资产
- 在本地 Browser Runner 渠道中支持“仅模拟”：填写标题、正文和封面并完成校验，但不点击发布或保存草稿
- 根据文章内容，从任务关联图片库中筛选相关素材并生成 3:2 横版封面
- 对重复任务使用幂等键
- 记录提交结果、远端文章 ID、文章链接和错误日志
- 复用分发队列完成失败重试
- 支持远端更新和删除接口

系统不提供或绕过头条平台账号权限。正式使用必须满足以下任一条件：

1. 企业头条账号已取得官方图文发布接口权限，并有与该权限对应的接口文档。
2. 已部署遵守平台规则的头条接入服务，由该服务处理官方授权、图片上传、内容提交和平台审核状态。

本地 Browser Runner 只复用运营人员已经登录的浏览器会话，不保存头条密码，也不会规避验证码或平台风控。遇到登录失效、验证码或平台确认时，必须由运营人员按平台规则处理。

## Browser Runner 模拟模式

渠道类型选择“本地浏览器发布助手”，平台选择“今日头条”，发布模式选择“仅模拟”。模拟任务会打开头条编辑器，填写并校验标题、正文和封面；校验通过后任务状态记为“已模拟”，不会产生远端文章 ID，也不会点击发布或保存草稿。模拟结果不能视为已向今日头条提交。

模拟和正式发布都要求可信的封面上传证据。若文章任务配置了图片库，系统会从该图片库最多选取 4 张与标题、摘要、关键词和正文相关的素材，结合文章内容调用配置的图片模型生成封面。生成结果会写回原图片库并作为文章首图；相同文章内容和参考素材的重试会复用已生成封面。

封面生成会把文章标题、摘要等必要内容以及选中的参考图片发送给配置的外部 AI 服务商。启用前必须确认素材版权、个人信息和商业数据均允许交由该服务商处理。图片库已配置但没有有效素材时，任务会明确失败，不会绕过要求使用无关图片。

## 发布流程

```text
文章审核通过
    -> 点击发布
    -> 创建今日头条分发任务
    -> distribution 队列发送文章载荷
    -> 官方接口或合规接入服务
    -> 返回远端文章 ID 和链接
    -> 点签记录成功或安排重试
```

接口返回成功代表内容已被接入端接受。今日头条可能继续进行平台审核，因此不能把“提交成功”等同于“已经公开展示”。

## 后台配置

1. 进入“内容分发”，点击“新增渠道”。
2. 渠道类型选择“今日头条”。
3. 目标域名填写 `www.toutiao.com`。
4. API 基础地址填写获批接口或接入服务的 HTTPS 地址。
5. 按接口要求选择 Bearer Token、自定义 Header Key、Basic Auth 或 HMAC。
6. 填写健康检查、发布、更新和删除路径。
7. 配置响应中的远端 ID、文章 URL 字段路径。
8. 保存后点击“测试连接”。
9. 在内容生产任务中关联该渠道，并把发布范围设置为包含渠道分发。

使用 Browser Runner 时，改为选择“本地浏览器发布助手”，填写本机 Runner 的配对 Token 和头条账号标识，并选择“仅模拟”“保存草稿”或“正式发布”。封面生成功能默认使用 Gemini，可通过 `GEOFLOW_TOUTIAO_COVER_*` 配置项调整，并需要设置 `GEMINI_API_KEY` 或所选服务商对应的密钥。

首次联调建议只发布一篇非敏感测试文章，并在头条后台核对标题、正文、图片、账号归属和审核状态。

## 接入服务协议

默认接口约定如下，路径可在后台调整：

| 操作 | 默认方法 | 默认路径 |
| --- | --- | --- |
| 健康检查 | `GET` | `/health` |
| 发布文章 | `POST` | `/articles` |
| 更新文章 | `POST` | `/articles/{remote_id}` |
| 删除文章 | `DELETE` | `/articles/{remote_id}` |

发布请求使用 JSON，核心结构如下：

```json
{
  "version": "1.0",
  "source": "geoflow",
  "event": "article.publish",
  "distribution_target": {
    "platform": "toutiao",
    "content_type": "article"
  },
  "article": {
    "id": 123,
    "title": "文章标题",
    "slug": "article-slug",
    "excerpt": "摘要",
    "content": "Markdown 正文",
    "content_format": "markdown",
    "content_html": "<p>HTML 正文</p>",
    "hero_image_url": "https://example.com/cover.jpg",
    "keywords": "关键词",
    "published_at": "2026-07-22T10:00:00+08:00"
  },
  "assets": {
    "images": []
  }
}
```

接入服务至少应返回可唯一标识远端文章的 ID，并尽量返回可访问链接：

```json
{
  "id": "toutiao-article-id",
  "url": "https://www.toutiao.com/article/example"
}
```

如果接口把字段放在 `data` 中，应在后台把远端 ID 路径设为 `data.id`，文章 URL 路径设为 `data.url`。

## 联调清单

- [ ] 头条账号主体已确认接口权限和允许的内容类型
- [ ] 接入地址使用 HTTPS
- [ ] Token 只通过后台保存，未写入源码或文档
- [ ] “测试连接”成功
- [ ] 测试文章只关联一个今日头条渠道
- [ ] 接入端支持幂等键，重复请求不会重复发文
- [ ] 图片可以从公网 URL 获取，或由接入端读取 `content_base64`
- [ ] 任务已关联有授权素材的图片库，并已确认外部图片模型的数据处理条款
- [ ] Browser Runner 已完成本机配对，头条账号处于有效登录状态
- [ ] 首次运行先选择“仅模拟”，确认标题、正文和生成封面均正确且没有触发提交
- [ ] 返回值包含远端文章 ID 和链接
- [ ] 已在头条后台确认平台审核结果
